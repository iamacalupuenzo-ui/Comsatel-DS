# Comsatel DS v0.3.11

## Resumen

`Select` ajusta tres detalles: la X de limpiar pasa a ser opcional, el placeholder deja la cursiva y el modo chips muestra un chip y luego «+N».

## Cambios

- `showClear` pasa a `false` por defecto. Elegir otra opción ya reemplaza el valor, así que la X solo aporta en campos no obligatorios. Es el mismo criterio de Ant Design (`allowClear`) y react-select (`isClearable`), donde es opcional. En MUI Select no existe.
- El placeholder vacío deja la cursiva y usa el tono tenue, igual que Input.
- `maxVisibleChips` pasa a 1 por defecto, y cada chip recorta su texto a 120 px como máximo. El resto se resume en «+N», como `limitTags` de MUI o `maxTagCount` de Ant Design.
- Sitio: el playground suma el control «Botón limpiar (simple)», y los textos de chips y del estado «Con valor» reflejan los nuevos valores por defecto.

## Impacto para consumidores

Si usabas Select simple y querías la X, agrega `[showClear]="true"`. Si querías dos chips visibles, usa `[maxVisibleChips]="2"`.

## Verificación

- `npm run check:docs`, `npx ng build comsatel-ds` y la compilación del sitio completados localmente.
