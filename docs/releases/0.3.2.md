# Comsatel DS v0.3.2

## Resumen

Corrige la tipografía del valor precargado por el autocompletado del navegador y unifica el tratamiento del autocompletado en `Input` e `InputGroupInput`.

## Cambios

- Mientras el valor precargado no se confirma, Chrome lo dibujaba con su fuente de sistema (~13 px): se veía más pequeño hasta el primer clic. `Input` e `InputGroupInput` fijan la tipografía real en `:-webkit-autofill::first-line`.
- `Input` deja la sombra interior de 1000px y usa `background-clip: text`, igual que `InputGroupInput` desde la v0.3.1: el campo precargado no se sombrea y conserva borde, foco y error.

## Impacto para consumidores

No cambia la API pública. Los campos con valores guardados por el navegador se ven con el mismo tamaño y color de texto que uno escrito a mano.

## Verificación

- `npm run check:docs` y `npx ng build comsatel-ds` completados localmente.
- Pendiente: validación en navegador con un correo guardado.
