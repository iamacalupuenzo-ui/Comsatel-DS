# Comsatel DS v0.1.3

Estado: Preparada para publicarse

## Resumen

Corrige la resolución de los assets de C-Locater Flotas en aplicaciones Angular
que pre-empaquetan la librería con Vite.

## Cambios

- Las URLs del logotipo y el isotipo pasan a ser referencias estáticas.
- Vite puede detectar y reescribir cada PNG durante el pre-bundling ESM.

## Impacto para consumidores

No hay migración de API. Actualiza a `0.1.3`; no uses `--prebundle=false`
como solución permanente.

## Verificación

- `npm run build:lib` compiló las URLs estáticas y los assets públicos.
- `npm run check:release-notes` validó esta nota.
- `npm pack ./dist/comsatel-ds --dry-run` confirmó ambos PNG en `0.1.3`.
