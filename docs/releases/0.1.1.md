# Comsatel DS v0.1.1

Estado: Preparada para publicarse

## Resumen

Se incorpora un punto de entrada público de estilos para que las aplicaciones
Angular consumidoras puedan aplicar los tokens y fuentes oficiales sin copiar
archivos internos del Design System.

## Cambios

- Se publica `@iamacalupuenzo-ui/comsatel-ds/styles.css`.
- El paquete incluye `styles.css`, `tokens.css` y `typography-tokens.css`.
- El build valida que los tres archivos se empaqueten y que `styles.css` esté
  declarado en los exports públicos.
- Se documenta el único import requerido por una aplicación consumidora.

## Impacto para consumidores

- No hay migración obligatoria para consumidores de componentes sin estilos.
- Para adoptar los tokens y fuentes, actualizar a `0.1.1` e importar una vez
  `@iamacalupuenzo-ui/comsatel-ds/styles.css` en los estilos globales.
- El punto de entrada no inyecta resets ni estilos de demos; cada aplicación
  mantiene el control de su CSS global y de sus pantallas de producto.

## Verificación

- `npm run check:docs` valida la nota y las guías actualizadas.
- `npm run build:lib` comprueba el contenido de `dist/comsatel-ds` y exporta
  el punto de entrada de estilos.
- `npm pack --dry-run` verifica que los estilos públicos formen parte del
  paquete distribuible.
