# Comsatel DS v0.1.4

Estado: Listo para publicar

## Resumen

Aclara el contrato público para el patrón de contraseña con visibilidad.

## Cambios

- Se incorpora `PasswordInput` (`<cs-password-input>`) como composición oficial
  para contraseña con visibilidad.
- El componente encapsula el botón nativo, los íconos eye/eye-off, `aria-pressed`
  y las etiquetas accesibles; el consumidor conserva valor, validación y errores.
- El README y la guía pública diferencian el campo de contraseña especializado del
  correo genérico (`cs-input type="email"`) y aclaran que consumir el paquete solo
  requiere `read:packages`, nunca alcance `repo`.

## Impacto para consumidores

No hay una ruptura de API. Al crear o actualizar un login, reemplaza la
composición manual de contraseña por `PasswordInput`; no uses `cs-button` dentro
del addon. Las composiciones manuales existentes siguen funcionando, pero ya no
son el patrón recomendado.

## Verificación

Validado localmente el 2026-09-15 con `npm run check:docs`, `npm run test:ci`,
`npm run pack:lib` y `npm run build-storybook`. La comprobación de documentación
validó 56/56 guías, 44 ejemplos y 17 pruebas; el empaquetado generó el paquete
seco v0.1.4 con los estilos públicos y los assets de marca.
