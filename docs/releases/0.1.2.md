# Comsatel DS v0.1.2

Estado: Preparada para publicarse

## Resumen

Se incorpora la identidad visual pública de C-Locater Flotas by Comsatel.

## Cambios

- Se añade `CLocaterFlotasLogo` con selector `cs-c-locater-flotas-logo`.
- Se publican PNG del logotipo horizontal y del isotipo dentro del paquete.
- La API ofrece variantes `full` e `icon`, tamaños `sm`, `md` y `lg`, y
  alternativas accesibles mediante `alt` y `decorative`.

## Impacto para consumidores

No hay migración. Las aplicaciones pueden sustituir un wordmark local por el
componente público después de actualizar a `@iamacalupuenzo-ui/comsatel-ds@0.1.2`.

## Verificación

- `npm run build:lib` compiló la librería y confirmó el punto de entrada de
  estilos públicos.
- `ng build` compiló la aplicación de documentación con ambas variantes en la
  página de Logos.
- `npm run check:release-notes` validó esta nota.
- `npm pack ./dist/comsatel-ds --dry-run` confirmó que ambos PNG se incluyen
  en el paquete distribuible.
