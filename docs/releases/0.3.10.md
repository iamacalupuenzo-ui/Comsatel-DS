# Comsatel DS v0.3.10

## Resumen

El menú de `Dropdown` deja de tener un ancho fijo (192 o 220 px) y mide su opción más larga, entre 128 y 280 px.

## Cambios

- `Dropdown`: el menú usa `width: max-content`, con un mínimo de 128 px y un máximo de 280 px. Los ítems que no caben se recortan con puntos suspensivos. Es el mismo criterio de Material Design y Radix.
- Guía: nueva sección «Ancho del menú» en `guidelines/dropdown.md`.

## Impacto para consumidores

Los menús de pocas opciones cortas se ven más angostos. Si fijabas el ancho del menú con CSS propio, quítalo para usar el del DS.

## Verificación

- `npm run check:docs`, `npx ng build comsatel-ds` y la compilación del sitio completados localmente.
