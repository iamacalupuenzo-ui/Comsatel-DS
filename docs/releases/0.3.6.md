# Comsatel DS v0.3.6

## Resumen

`InputDropdown` acepta un ícono decorativo al inicio del campo (`leadingIcon`), para filtros compactos que se reconocen por su ícono.

## Cambios

- Nueva entrada `leadingIcon?: IconName` en `InputDropdown`. El ícono usa el tono del chevron, toma el color de selección con `active` y el de deshabilitado cuando corresponde. El ancho medido del campo lo incluye.
- Sitio: el playground de Input Dropdown suma el control «Ícono al inicio» y el estado «Con ícono al inicio» en su propia caja, con su código.

## Impacto para consumidores

No cambia el comportamiento existente. Permite reemplazar filtros propios con ícono, como los del panel del mapa en FleetOperations.

## Verificación

- `npm run check:docs` y `npx ng build comsatel-ds` completados localmente.
