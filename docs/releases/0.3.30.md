# Comsatel DS v0.3.30

## Resumen

MapPanel y MapSearch ya no se contraen cuando Escape cierra un selector que está adentro.

## Cambios

- **MapPanel**: ignora un Escape que otro componente ya usó (`preventDefault`), como el cierre de un `cs-input-dropdown` abierto dentro del panel. Cada Escape cierra una sola capa.

## Impacto para consumidores

Sin cambios que rompan. Los filtros del buscador del mapa se cierran con Escape sin contraer el panel.

- `npx ng build comsatel-ds`
- `npm run check:docs`
