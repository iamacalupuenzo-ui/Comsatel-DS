# Comsatel DS v0.3.1

## Resumen

Corrige la geometría de `InputGroup` cuando el navegador precarga valores mediante autocompletado.

## Cambios

- `InputGroupInput` ya no usa una sombra interior de gran tamaño para neutralizar el fondo de `:-webkit-autofill`.
- El autocompletado conserva el color del texto y del caret con `background-clip: text`, sin cubrir el borde ni la superficie del grupo.

## Impacto para consumidores

No cambia la API pública. Los formularios que usan `cs-input-group` con valores guardados por el navegador conservan su borde y composición visual.

## Verificación

- `npm run build:lib` completado localmente.
- Pendiente: validación en navegador con un valor precargado y publicación en GitHub Packages.
