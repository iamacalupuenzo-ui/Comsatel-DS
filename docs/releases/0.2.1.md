# Comsatel DS v0.2.1

## Resumen

Se alinea la identidad de Flotas con la familia C-Locator: el recurso público
ahora comunica `C-Flotas by Comsatel` y ofrece el isotipo `CF` sin depender de
rutas internas de `node_modules`.

## Cambios

- Se incorpora el selector canónico `cs-c-flotas-logo` y la clase
  `CFlotasLogo`.
- El componente expone `variant="wordmark"` e `variant="isotype"`; el
  wordmark usa el ancho disponible con `fit="container"` sin deformarse.
- Los SVG de wordmark e isotipo se entregan como recursos auto-contenidos,
  compatibles con el pre-bundling de Vite.
- `cs-c-locater-flotas-logo`, `CLocaterFlotasLogo`, `variant="full"` y
  `variant="icon"` permanecen como aliases de compatibilidad.
- La guía, README, página de Logos y Storybook documentan el API canónico y
  las dos variantes.

## Impacto para consumidores

No hay cambio incompatible. Las aplicaciones existentes conservan el selector
y valores históricos; los usos nuevos deben preferir `cs-c-flotas-logo`,
`CFlotasLogo`, `wordmark` e `isotype`.

## Verificación

Validado localmente el 2026-09-17 con `npm run build`, `npm run check:docs`,
`npm run test:ci`, `npm run build-storybook` y
`npm pack ./dist/comsatel-ds --dry-run --json`. Se revisó además
