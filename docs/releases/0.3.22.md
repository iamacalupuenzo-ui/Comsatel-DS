# Comsatel DS v0.3.22

## Resumen

Dos componentes nuevos para la estructura de una pantalla: EmptyState y PageHeader.

## Cambios

- **EmptyState (`cs-empty-state`)**: ícono opcional, título, descripción y acciones proyectadas; se anuncia con `role="status"`. Pensado para `[emptyState]` de Table y zonas sin resultados.
- **PageHeader (`cs-page-header`)**: título `h1` con `titleId` para `aria-labelledby`, descripción y acciones proyectadas a la derecha. Hasta 960 px las acciones bajan; hasta 767 px se apilan.
- PageHeader usa un `div`, no `header`: fuera de una sección, `header` se anuncia como el banner de toda la página.
- Guías e historias de Storybook. Las páginas del sitio se suman en la próxima versión.

## Impacto para consumidores

Sin cambios que rompan. Un estado vacío o un encabezado de pantalla propios pueden pasar a estos componentes y retirar sus estilos locales.

## Verificación

- `npx ng build comsatel-ds`
- `npx ngc -p tsconfig.app.json --noEmit`
- `npm run check:docs`
- Storybook revisado con Playwright: EmptyState se anuncia como estado con su botón; PageHeader expone un `h1` y sus dos acciones, sin landmark de banner.
