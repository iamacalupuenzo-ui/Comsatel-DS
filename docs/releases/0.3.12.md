# Comsatel DS v0.3.12

## Resumen

Dos componentes nuevos de formulario, Textarea y FormField, y páginas nuevas en el sitio para Skeleton, Column manager y Fleet unit list.

## Cambios

- **Textarea (`cs-textarea`)**: texto de varias líneas con label, ayuda, error, contador opcional (`maxLength`, tono de aviso al 90 %), solo lectura, deshabilitado y `resize` vertical o fijo.
- **FormField (`cs-form-field`)**: envoltorio con label, ayuda y error para controles sin label propio; genera los ids `{for}-label`, `{for}-help` y `{for}-error`.
- Sitio: páginas de Textarea, Form field, Skeleton, Column manager y Fleet unit list, con playground y estados.

## Impacto para consumidores

Sin cambios que rompan. Los campos de descripción u observación escritos con `cs-input` pueden pasar a `cs-textarea`. Los envoltorios locales de label + ayuda + error pueden pasar a `cs-form-field`.

## Verificación

- `npx ng build comsatel-ds`
- `npx ngc -p tsconfig.app.json --noEmit`
- `npm run check:docs`
