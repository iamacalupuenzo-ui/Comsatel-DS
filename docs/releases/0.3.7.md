# Comsatel DS v0.3.7

## Resumen

Nuevo componente `Autocomplete`: un campo de búsqueda que filtra una lista larga mientras se escribe y permite elegir una opción.

## Cambios

- `cs-autocomplete` con opciones `{ value, label, description?, icon?, searchText?, disabled? }`, mínimo de caracteres (`minChars`), tamaños sm/md/lg, ícono inicial, X para limpiar, texto vacío y los estados requerido, error con mensaje, filtro aplicado, solo lectura y deshabilitado.
- Patrón combobox de ARIA: el foco se queda en el campo y la opción activa se anuncia con `aria-activedescendant`. Flechas, Enter y Escape; Escape cierra solo la lista.
- La lista usa Popover, así que se ve por encima de modales y cajones.
- `InputGroupInput` acepta `role` y `ariaActivedescendant`.
- Sitio: nueva página Autocomplete con playground, una caja por estado y casos de uso (buscar una unidad por placa, motor o DNI y buscar un comando GPS). Guía en `guidelines/autocomplete.md`.

## Impacto para consumidores

Componente nuevo; no cambia los existentes. Reemplaza los autocompletados propios del producto.

## Verificación

- `npm run check:docs`, `npx ng build comsatel-ds` y la compilación del sitio completados localmente.
- Probado en el sitio con Playwright: filtrado, navegación con flechas y elección con Enter.
