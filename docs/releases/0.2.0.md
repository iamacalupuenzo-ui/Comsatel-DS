# Comsatel DS v0.2.0

## Resumen

Se corrige la distribución del wordmark de C-Locater Flotas para que el asset
se resuelva en aplicaciones Angular pre-empaquetadas con Vite.

## Cambios

- `cs-c-locater-flotas-logo` ahora muestra exclusivamente el wordmark de
  C-Locater Flotas by Comsatel, sin isotipo.
- Se elimina la propiedad pública `variant` y, con ella, `variant="icon"`.
- El wordmark se embebe en el componente para que Vite no lo resuelva desde
  su caché de pre-bundling ni exija copiar assets de node_modules.
- `fit="container"` permite usar el ancho disponible del contenedor sin
  deformar el wordmark.
- El paquete deja de distribuir los PNG históricos de logo completo e
  isotipo; solo conserva el recurso del wordmark.
- Se publica `fieldLabelTypography` para asociar la tipografía de las
  etiquetas de campo con `xs | sm | md | lg`, y Select, InputDropdown y los
  selectores de fecha/hora ya la aplican internamente.
- `Input`, `InputGroupInput` y `PasswordInput` conservan su etiqueta externa;
  la guía incluye la receta para aplicar la misma escala desde un formulario.

## Impacto para consumidores

Cambio incompatible: elimina cualquier uso de `variant="icon"` y conserva
`size`, `fit`, `alt` y `decorative`. No hay migración para el isotipo porque la
identidad aprobada del componente es únicamente el wordmark.

## Verificación

Validado localmente el 2026-09-16 con `npm run check:docs`, `npm run
test:ci`, `npm run build` y `npm pack ./dist/comsatel-ds --dry-run --json`.
El bundle FESM no contiene `new URL(...)` para este componente ni la variante
pública `icon`; la documentación local muestra el wordmark en modo
`fit="container"` sin solicitudes de assets internos.
