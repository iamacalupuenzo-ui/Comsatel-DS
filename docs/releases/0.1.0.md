# Comsatel DS v0.1.0

Estado: Preparada para publicarse

## Resumen

Primera distribución privada de la biblioteca Angular del Sistema de Diseño
Comsatel mediante GitHub Packages.

## Cambios

- Se publica la superficie pública compilada como `@iamacalupuenzo-ui/comsatel-ds`.
- Se incorpora un workflow que valida documentación, pruebas, Storybook y
  agent-readiness antes de publicar.
- Se documenta el registro privado, la autenticación de lectura y el flujo de
  adopción controlada por versión.

## Impacto para consumidores

- Requiere Angular 22 como dependencia de pares.
- Cada plataforma configura el registro de GitHub Packages y un token clásico
  con permiso `read:packages` antes de instalar.
- No existen migraciones desde una versión pública anterior: esta es la primera
  versión distribuida. Las plataformas deben instalar una versión explícita y
  actualizar su lockfile en un cambio revisable.

## Verificación

- `npm run check:docs`: 54/54 guías, 43 ejemplos y 16 pruebas de validadores.
- `npm run test:ci`: 2/2 pruebas unitarias.
- `npm run build-storybook`, `npm run pack:lib` y el gate de agent-readiness
  completados antes de preparar la versión.
