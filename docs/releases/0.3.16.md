# Comsatel DS v0.3.16

## Resumen

Corrige el label de ColumnManager, que no tomaba la tipografía de campo y se veía más grande que los de Input dropdown a su lado.

## Cambios

- **ColumnManager**: el label usa la misma tipografía de campo que Input dropdown del mismo tamaño y el mismo espacio respecto del campo. Antes heredaba el tamaño de texto de la página.
- **ColumnManager**: con `label=""` ya no deja un span vacío ni apunta `aria-labelledby` a él; el nombre accesible sale de `aria-label`.

## Impacto para consumidores

Sin cambios de API. El label de ColumnManager se ve más chico y alineado con los demás filtros. Quien lo usaba sin label no ve cambios visuales.

## Verificación

- `npx ng build comsatel-ds`
- `npm run check:docs`
- Sitio revisado con Playwright: Estado, Filas y Columnas con label de 12 px y los campos alineados a la misma altura.
