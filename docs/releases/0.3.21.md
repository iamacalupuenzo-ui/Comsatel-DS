# Comsatel DS v0.3.21

## Resumen

Nuevo componente DescriptionList para mostrar el detalle de un registro como pares etiqueta y valor.

## Cambios

- **DescriptionList (`dl[csDescriptionList]`)**: grilla de una o dos columnas (`columns`) sobre un `<dl>` nativo; hasta 767 px pasa a una columna.
- **DescriptionItem (`div[csDescriptionItem]`)**: par etiqueta y valor con `label`, valor proyectado (texto, ícono con texto o Tag), `fullWidth` para textos largos y un lápiz de edición opcional (`editLabel` y `(edit)`).
- Se aplican con selectores de atributo para conservar la semántica de término y definición que leen los lectores de pantalla.
- Guía `guidelines/description-list.md` e historias de Storybook. La página del sitio se suma en la próxima versión.

## Impacto para consumidores

Sin cambios que rompan. Una lista de detalle propia (`<dl>` con estilos locales) puede pasar a `csDescriptionList` y `csDescriptionItem` y retirar esos estilos.

## Verificación

- `npx ng build comsatel-ds`
- `npx ngc -p tsconfig.app.json --noEmit`
- `npm run check:docs`
- Storybook revisado con Playwright: estructura `dl > div > dt + dd`, dos columnas y árbol de accesibilidad con pares término y definición.
