# Comsatel DS v0.2.2

## Resumen

Se corrige la construcción visual de C-Flotas para que conserve la misma
anatomía de marca de C-Locator.

## Cambios

- El wordmark usa la estructura `C-` + cápsula negra `FLOTAS` + firma
  `by COMSATEL` en una sola línea.
- El isotipo usa la estructura `C-` + cápsula negra `FL`, apta para railes y
  contextos compactos.
- Se actualizan los textos de guía, README y documentación para nombrar el
  isotipo C-FL de forma consistente.

## Impacto para consumidores

No cambia el selector, la clase, las variantes ni la accesibilidad. Las
aplicaciones que ya consumen `cs-c-flotas-logo` reciben la corrección visual
al actualizar a esta versión.

## Verificación

Validado localmente con compilación de librería y aplicación, chequeos de
documentación, pruebas y revisión visual de `/foundations/logos`.
