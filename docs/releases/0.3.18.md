# Comsatel DS v0.3.18

## Resumen

Corrige un id duplicado que dejaba sin nombre accesible a los campos enlazados con `<label for>`.

## Cambios

- Los componentes que reciben `id` ya no lo repiten en su elemento host: Input, InputGroupInput, PasswordInput, Textarea, InputDropdown, Select, Autocomplete, Radio, DateRangePicker, DateTimeRangePicker, TimePicker y Popover.
- Antes, `<cs-input id="placa">` dejaba dos elementos con `id="placa"`: el host y el `<input>`. Un `<label for="placa">` apuntaba al host, que no es un control, así que el campo quedaba sin nombre accesible y el clic en el label no lo enfocaba.

## Impacto para consumidores

Sin cambios de API. Los `<label for>` propios y FormField ahora nombran el control correcto. Si algún selector o prueba buscaba el id en el host (`cs-input#placa`), debe apuntar al control (`input#placa`).

## Verificación

- `npx ng build comsatel-ds`
- `npm run check:docs`
- Sitio revisado con Playwright: en Form field hay un solo elemento con el id, `label.control` es el `<input>` y el campo se encuentra por su nombre.
