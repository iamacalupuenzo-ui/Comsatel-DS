# Comsatel DS v0.3.25

## Resumen

Carga de archivos: una zona para arrastrar o elegir archivos y la fila de cada archivo adjunto. Suma tres íconos.

## Cambios

- **FileDropzone (`cs-file-dropzone`)**: arrastrar o seleccionar, con `accept`, `multiple`, `hint`, estado visual al arrastrar, `disabled` y `errorMessage` con `role="alert"`. Emite `(filesSelected)` con los archivos; la validación queda en la pantalla.
- **FileItem (`cs-file-item`)**: ícono según la extensión, nombre (con enlace si hay `href`), tamaño legible, botón de quitar con `removeLabel` y acciones proyectadas.
- Funciones `fileIconFor()` y `formatFileSize()`.
- Íconos nuevos: `video`, `music` y `upload` (Lucide).
- Guía e historias de Storybook. La página del sitio se suma en la próxima versión.

## Impacto para consumidores

Sin cambios que rompan. Una zona de carga o una lista de adjuntos propias pueden pasar a estos componentes. La validación de formato y tamaño sigue siendo de la pantalla.

## Verificación

- `npx ng build comsatel-ds`
- `npx ngc -p tsconfig.app.json --noEmit`
- `npm run check:docs`
