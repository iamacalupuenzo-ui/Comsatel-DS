# Comsatel DS v0.3.3

## Resumen

Corrige la capa de Popover cuando su disparador está dentro de un modal.

## Cambios

- Popover usa `--elevation-z-index-overlay` si el disparador está dentro de `.cs-modal` o `[aria-modal="true"]`; en los demás casos conserva `--elevation-z-index-dropdown`.
- Storybook y el sitio muestran un Select dentro de un modal con el menú visible sobre la máscara.

## Impacto para consumidores

No cambia la API pública. Los consumidores pueden retirar los ajustes locales que elevaban la capa dropdown durante un modal.

## Verificación

- `npm run check:docs`, `npm run test:ci` y `npx ng build comsatel-ds` completados localmente.
- Menú de Select verificado en navegador dentro de un modal.
