# Comsatel DS v0.3.5

## Resumen

Marca como obsoleta la superficie crema (`surface="secondary"` y los tokens `*-secondary-*`), que se descartó. Se eliminará en 0.4.0.

## Cambios

- `InputDropdown`, `Select`, `ActionCard` y `FleetUnitList`: la entrada `surface` con valor `'secondary'` queda marcada `@deprecated`.
- Guías (`dropdown`, `select`, `card`, `fleet-unit-list`, `design-tokens`) y la página de Color indican que la crema está obsoleta.
- El sitio ya no muestra el ejemplo de Input Dropdown sobre superficie crema.
- Páginas de Input, Input Dropdown y Select: cada estado en su propia caja, con descripción, código y selector de tamaño.

## Impacto para consumidores

No cambia el comportamiento: `surface="secondary"` sigue funcionando hasta 0.4.0. Si lo usas, cámbialo a la superficie por defecto.

## Verificación

- `npm run check:docs` y `npx ng build comsatel-ds` completados localmente.
- Pendiente: retirar las historias de Storybook que muestran la superficie crema.
