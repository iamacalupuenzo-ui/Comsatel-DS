# Comsatel DS v0.3.26

## Resumen

La búsqueda de FilterBar usa la X del sistema de diseño en vez de la del navegador.

## Cambios

- **FilterBar**: el campo de búsqueda pasa de `type="search"` a `type="text"` y suma `cs-input-group-clear`. Antes, cada navegador dibujaba su propia X (distinta en Chrome, Edge y Safari) y no coincidía con el resto de los buscadores del sistema.
- Nueva entrada `clearSearchLabel` (predeterminado «Limpiar búsqueda») para el nombre accesible del botón.

## Impacto para consumidores

Sin cambios de API que rompan. La X aparece al escribir y, al usarla, `(searchChange)` emite un texto vacío.

## Verificación

- `npx ng build comsatel-ds`
- `npm run check:docs`
- Sitio revisado con Playwright: el campo es `type="text"`, la X aparece al escribir, limpia el valor y desaparece.
