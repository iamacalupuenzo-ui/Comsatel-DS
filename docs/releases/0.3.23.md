# Comsatel DS v0.3.23

## Resumen

Nuevo componente Timeline para el historial de estados de un registro.

## Cambios

- **Timeline (`ol[csTimeline]`)** y **TimelineItem (`li[csTimelineItem]`)**: pasos con `title`, `time` (con `dateTime` ISO opcional), `description` y contenido proyectado; líneas que unen cada paso y `current` para el paso vigente, con `aria-current="step"`.
- Se aplican sobre `<ol>` y `<li>` nativos para conservar la semántica de lista ordenada.
- Guía e historia de Storybook. La página del sitio se suma en la próxima versión.

## Impacto para consumidores

Sin cambios que rompan. Un historial propio con marcadores y línea puede pasar a `csTimeline` y retirar sus estilos.

## Verificación

- `npx ng build comsatel-ds`
- `npx ngc -p tsconfig.app.json --noEmit`
- `npm run check:docs`
