# Comsatel DS v0.3.4

## Resumen

Completa la selección múltiple de `cs-select` para filtros y formularios.

## Cambios

- Los chips se mantienen en una línea: dos visibles por defecto y `+N` para el resto; `maxVisibleChips` permite ajustar el límite.
- En ambos modos, todas las opciones marcadas equivalen a «todos» y no muestran filtro aplicado.
- El sitio, las guías y Storybook documentan los estados del modo múltiple.

## Impacto para consumidores

La API nueva es opcional y conserva el valor predeterminado `multipleDisplay="chips"`. Para filtros estrechos usa `multipleDisplay="summary"`, `menuFit` y `active` con una selección parcial.

## Verificación

- `npm run docs`, `npm run check:docs` y `npm run build:lib`.
- Estados y tamaños revisados con Playwright aislado; evidencia en el informe de la migración.
