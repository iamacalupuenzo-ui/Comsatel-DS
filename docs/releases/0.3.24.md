# Comsatel DS v0.3.24

## Resumen

Nuevo componente Stat para los indicadores de un tablero, con el color de la variación según qué dirección es buena.

## Cambios

- **Stat (`cs-stat`)**: `label`, `value`, `caption`, `delta` y tamaños `lg` y `sm`.
- **`trend`** (`'up-is-good' | 'down-is-good' | 'neutral'`): define si la variación se pinta en verde o en rojo. Una variación de 0 siempre es neutra.
- Guía e historias de Storybook. La página del sitio se suma en la próxima versión.

## Impacto para consumidores

Sin cambios que rompan. Una tarjeta de indicador propia puede pasar a `cs-stat`. Revisa `trend` en cada indicador: donde subir es malo, usa `down-is-good`.

## Verificación

- `npx ng build comsatel-ds`
- `npx ngc -p tsconfig.app.json --noEmit`
- `npm run check:docs`
