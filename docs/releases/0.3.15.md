# Comsatel DS v0.3.15

## Resumen

Modal gana la propiedad `surface`, con el mismo contrato que SideDrawer.

## Cambios

- **Modal `surface`** (`'default' | 'canvas'`): `canvas` pinta el panel con `--color-background-canvas`, para modales con campos o tarjetas blancas encima. Nuevo tipo `ModalSurface`.
- Sitio: control «Superficie» en el playground de Modal y sección en la guía.

## Impacto para consumidores

Sin cambios que rompan. Quien sobrescribía `--elevation-surface-overlay` en una clase propia para darle el lienzo al Modal puede pasar a `surface="canvas"` y retirar esa regla.

## Verificación

- `npx ng build comsatel-ds`
- `npx ngc -p tsconfig.app.json --noEmit`
- `npm run check:docs`
