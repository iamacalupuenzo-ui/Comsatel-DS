Accordion

Un accordion deja que cada ítem se expanda para mostrar más detalle sin salir de la lista — una unidad de flota que se expande a su tarjeta de estado completa. Por defecto solo un ítem queda abierto a la vez, que es como se lee una lista así: enfocarse en una cosa, no varios paneles abiertos compitiendo por la atención.

Dos alternativas de superficie

Ambas mantienen identidad, estado y telemetría en el mismo orden. La alternativa delineada separa mejor unidades con información densa; la rellena reduce el peso del contorno cuando la lista ya vive dentro de una superficie delimitada.

A · Tarjetas delineadasMayor separación entre unidades.
B · Superficies rellenasMenos borde; útil dentro de otro panel.

Tipo

single (por defecto) cierra el ítem anterior cuando se abre uno nuevo. multiple permite cualquier cantidad abierta a la vez — útil cuando los ítems son independientes, no una vista enfocada en uno solo como una lista de flota.

Ítem deshabilitado

Un ítem deshabilitado no se puede abrir/cerrar — su encabezado se atenúa y pierde el cursor de puntero, pero se sigue mostrando en su lugar para que la lista no salte.

Lineamientos de uso

Recomendado

Usa Accordion cuando expandir el detalle de un ítem es el punto — el estado completo de una unidad de flota, una respuesta de FAQ, una sección de configuración.

Evita

No uses Accordion para esconder contenido que alguien necesita comparar entre ítems a la vez — una tabla o una lista con columnas visibles se lee mejor para eso.

Velocidad de unidadesCamión Norte 04 62 km/hCamión Norte 07 0 km/h
Recomendado

Usa type="single" por defecto para una lista donde tiene sentido enfocarse en un ítem a la vez — evita que la lista crezca de alto de forma impredecible.

<cs-fleet-unit-list type="single">
Evita

No recurras a type="multiple" solo porque está disponible — es para ítems independientes (un FAQ), no una lista pensada para enfocar la atención en una sola entrada.

<cs-fleet-unit-list type="multiple">

Accesibilidad

Cada encabezado es un botón nativo y su panel se anuncia como una región relacionada.

AspectoComportamiento
ControlEl encabezado usa un botón nativo con aria-expanded y nombre construido desde su contenido.
Relaciónaria-controls enlaza el botón con una región role="region" y aria-labelledby.
EstadoEl panel colapsado expone aria-hidden="true"; el contenido expandido vuelve a estar disponible para lectores de pantalla.
DisabledEl encabezado conserva el botón nativo disabled y no puede cambiar de estado.
TecladoEnter y Espacio alternan el panel; Flecha arriba/abajo, Inicio y Fin mueven el foco entre encabezados disponibles.
FocoEl encabezado tiene anillo visible; un panel cerrado queda inerte para que su contenido no entre al tabulador.
