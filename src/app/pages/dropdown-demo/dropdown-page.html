Dropdown

Los dropdowns presentan una lista de opciones activada por un botón, ícono o input. Admite ítems agrupados, atajos de teclado, badges, variantes destructiva/éxito, y tamaños xs / sm / md / lg.

Playground

Ajusta los controles para explorar los tipos de trigger, posiciones y tamaños.

Tipos de trigger

Usa un botón con etiqueta para acciones primarias, o un ícono de puntos suspensivos para menús secundarios o contextuales.

Ícono

Ítems agrupados

Usa la propiedad groups para organizar los ítems en secciones con encabezado separadas por divisores.

Variantes de ítem

Los ítems admiten tres variantes semánticas: default, destructive (peligro) y success.

Con atajos

Agrega un string de shortcut a cada ítem para mostrar el atajo de teclado al final de la fila.

Tamaños

Cuatro tamaños: xs (24px/11px), sm (28px/13px), md (32px/13px), lg (40px/14px).

Ítems de checkbox

Define selectionMode: "checkbox" en un grupo para ítems de selección múltiple: cada uno se marca de forma independiente y el menú permanece abierto para poder marcar más de uno.

Ítems de radio

Define selectionMode: "radio" en un grupo para ítems de selección única: elegir uno desmarca el resto de ese grupo, y el menú permanece abierto.

Input Dropdown — Playground

Input Dropdown — Estados

Placeholder (vacío), lleno (con valor seleccionado) y deshabilitado.

Lineamientos de uso

Cuándo usar cada variante y patrones comunes que evitar.

Dropdown

Recomendado

Úsalo para listas de acciones contextuales: editar, duplicar, eliminar.

Evita

No lo uses como un select de formulario: usa Input Dropdown para elegir un valor dentro de un formulario.

Recomendado

Agrupa acciones relacionadas con encabezados cuando hay muchos ítems.

Evita

No lo uses cuando solo hay una acción: usa un Button en su lugar.

Input Dropdown

Recomendado

Siempre acompáñalo de un label en contextos de formulario, por accesibilidad.

Evita

No omitas el label en formularios: el usuario pierde contexto sobre qué está seleccionando.

Recomendado

Usa el modo controlado (value + valueChange) para que el padre sea dueño del estado seleccionado.

<cs-input-dropdown
  [value]="team"
  (valueChange)="team = $event"
  [options]="options"
>
Evita

No uses Input Dropdown para disparar acciones: para eso está Dropdown.

<cs-input-dropdown
  [options]="[
    {{ '{' }} label: 'Exportar CSV' {{ '}' }},
    {{ '{' }} label: 'Eliminar todo' {{ '}' }},
  ]"
>
