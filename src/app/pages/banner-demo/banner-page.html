Banner

Un banner muestra un mensaje contextual persistente en la parte superior de una página o sección. Soporta cinco variantes semánticas, título opcional, cierre y acciones inline.

Accesibilidad

Banner comunica el contexto con texto, semántica visual y controles que se pueden operar con teclado.

AspectoComportamiento
Variante semánticaElige la variante por el significado del mensaje; el texto conserva la información aunque el color no se perciba.
ÍconoEl ícono acompaña la variante como apoyo visual y no reemplaza el título o el contenido textual del banner.
Título y cuerpoCuando existe title, se presenta antes del cuerpo para que la jerarquía se lea de forma predecible.
AccionesEl botón inline tiene una etiqueta visible, foco perceptible y emite actionClick para que el padre ejecute la acción.
CierreEl botón de cierre anuncia «Cerrar»; el padre controla la visibilidad y puede anunciar el resultado con una región aria-live.

Propiedades

PropiedadTipoPredeterminadoDescripción
variantBannerVariant"brand"Variante de color semántica. Controla el fondo, borde, ícono y color de texto.
titlestring—Encabezado opcional renderizado sobre el contenido en peso semibold.
iconbooleantrueMuestra u oculta el ícono principal.
action{{ '{ label: string }' }}—Renderiza un botón de texto inline debajo del contenido del mensaje.
dismissiblebooleanfalseSi es true, renderiza un botón de cierre. El padre es responsable de ocultar el banner.
(actionClick)EventEmitter<void>—Se emite cuando la persona activa la acción inline.
(dismiss)EventEmitter<void>—Se emite al activar el botón de cierre; el padre controla la visibilidad.
