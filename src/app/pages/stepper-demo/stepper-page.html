Componentes / Stepper

Stepper

Muestra el avance dentro de una secuencia fija y conocida. Cada paso comunica si está completado, activo o pendiente; no reemplaza una barra de carga ni una navegación general.

Playground

Cambia la orientación y el paso activo para revisar la geometría de los conectores.

Estados

Completado muestra una marca, activo un punto central y pendiente conserva el anillo vacío.

Orientación

Horizontal funciona con recorridos cortos; vertical deja más espacio para describir cada etapa.

Interacción opcional

Habilita la interacción solo cuando volver a un paso sea una acción válida dentro del flujo.

Accesibilidad

La semántica diferencia el estado informativo de una acción disponible.

AspectoComportamiento
EstructuraEl recorrido usa una lista y cada etapa se expone como un elemento de la lista.
EstadoEl paso vigente declara aria-current="step" y además conserva etiqueta textual.
TecladoEn modo informativo no añade paradas de foco. En modo interactivo cada nodo es un botón nativo, activable con Enter y Espacio.
AlcanceEs un indicador de estado; un wizard con paneles requiere relaciones de pestañas y no forma parte de este componente.

Lineamientos de uso

Usa la secuencia para comunicar progreso, no como un menú entre contenidos sin relación.

Recomendado

Representa un conjunto fijo de etapas que siguen un orden conocido.

Evita

No lo uses como navegación entre secciones independientes; utiliza Tab para ese propósito.

Recomendado

Mantén etiquetas breves, especialmente en orientación horizontal.

Evita

No incluyas párrafos dentro de una etapa; pon el detalle en el contenido asociado.
