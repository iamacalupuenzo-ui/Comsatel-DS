Componentes / Form field

Form fieldNuevo · v0.3.12

Envoltorio de un campo de formulario: label, el control, texto de ayuda y mensaje de error, con ids predecibles para enlazarlos. Úsalo con controles que no traen su propio label, como Input o InputGroup. Select, Autocomplete, Textarea y los selectores de fecha ya traen el suyo.

Playground

Cambia el mensaje y el requerido. El control usa como id el valor de for, y FormField genera los ids de la ayuda y del error.

  • {{ message() === 'none' ? 'Por defecto' : message() === 'helper' ? 'Con ayuda' : 'Con error' }}. {{ message() === 'helper' ? 'Aclara el dato esperado antes de escribir.' : message() === 'error' ? 'Indica cómo corregir el valor.' : 'Úsalo cuando la etiqueta basta para entender el campo.' }}
  • Propiedades: {{ message() === 'helper' ? 'helperText="…"' : message() === 'error' ? 'errorMessage="…"' : 'label="Código de unidad"' }}

Estados

Casos de uso

Con un campo con ícono

El mismo envoltorio sirve para InputGroup: el label se enlaza con el campo interno por su id.
