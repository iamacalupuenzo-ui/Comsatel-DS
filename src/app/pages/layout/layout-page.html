Layout

Layout define la estructura de una página: las áreas de navegación y contenido, y cómo responden al tamaño de pantalla. Todo producto construido sobre este sistema compone las mismas cuatro áreas, en el mismo orden, para que la navegación se comporte igual en todos lados.

Estructura

Las cuatro áreas se renderizan como hermanas dentro de la raíz de la página. El top nav va arriba de todo; side nav, main y panel comparten el resto de la altura en una fila.

Áreas del layout

Cada área tiene un solo trabajo. No renderices contenido de página dentro del side nav o el panel: son solo para navegación e información contextual.

Side nav: modos

El side nav nunca es redimensionable arrastrando — solo estos tres modos de ancho fijo. Cuál aplica por defecto depende del tamaño de pantalla; la elección manual del usuario se recuerda después, por encima del valor por defecto.

@for (m of modes; track m.name) {
{{ m.name }} {{ m.width }}

{{ m.desc }}

}

Breakpoints

Cinco tokens, declarados una sola vez y compartidos por cada decisión responsive del sistema — incluyendo qué modo de side nav aplica por defecto.

Uso

Top nav y side nav coordinan su estado (modo, drawer abierto) mediante un servicio compartido (SidenavState) inyectado en el Shell — no con inputs/outputs entre componentes hermanos.
