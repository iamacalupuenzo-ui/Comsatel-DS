Grids

La grilla alinea contenedores principales en el área de contenido. Los elementos dentro de cada contenedor se organizan con tokens de espaciado.

Anatomía

Columnas, gutters y márgenes crean una estructura predecible sin ocupar navegación ni paneles.

ColumnasDefinen el span de tarjetas, tablas, formularios e imágenes.
GuttersSeparan columnas con --layout-gap-lg.
MárgenesEl contenedor de página reserva el espacio exterior.

Spans de contenido

Tipos de grilla

Fija amplia

Opción predeterminada para dashboards, directorios y resultados con relaciones claras entre bloques.

Fija estrecha

Para lectura larga: limita la línea de texto y conserva la concentración del contenido.

Fluida

Para superficies que necesitan crecer horizontalmente, como tableros o mapas; úsala con moderación.

Respuesta por viewport

El breakpoint se determina por el viewport completo; side nav y panel no cambian la grilla elegida.

RangoColumnas y criterio
Escritorio12 columnas para contenido principal, paneles y grupos de métricas.
Tablet6 columnas; conserva el orden del DOM y reagrupa los spans.
Móvil2 columnas; los bloques de lectura ocupan todo el ancho disponible.

Grillas anidadas

Dentro de una tarjeta usa padding y gap del sistema. Crea una grilla interna solo cuando su contenido necesita una estructura de columnas propia.

Uso en código

.dashboard-grid { display: grid; grid-template-columns: repeat(12, minmax(0, 1fr)); gap: var(--layout-gap-lg); }
.dashboard-main { grid-column: span 8; }
.dashboard-panel { grid-column: span 4; }
@media (max-width: 1023px) { .dashboard-grid { grid-template-columns: repeat(6, minmax(0, 1fr)); } }
@media (max-width: 639px) { .dashboard-main, .dashboard-panel { grid-column: span 2; } }

Accesibilidad

La grilla es visual y no requiere role ARIA. Mantén el orden semántico del DOM, verifica el reflujo a 200–400% de zoom y no ocultes contenido por falta de ancho.

Lineamientos de uso

Recomendado

Alinea los contenedores principales a la grilla.

Evita

No invadas gutters ni uses columnas para botones e íconos.
