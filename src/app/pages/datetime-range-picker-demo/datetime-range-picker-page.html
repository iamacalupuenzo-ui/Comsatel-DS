Selector de rango de fecha y hora

Elige un rango de fechas más una sola ventana horaria diaria que aplica a todo el rango — "15 al 17 de sep, de 8:00 a. m. a 10:00 p. m." — para filtrar un historial o un reporte, no para agendar un único momento de inicio/fin. Para eso, usa Date time picker.

Playground

Haz clic en el campo para elegir un rango de fechas en el calendario, luego define la ventana horaria diaria.

Requerido y validación

Deshabilitado

Accesibilidad

El rango mantiene una sola decisión de fechas y una ventana horaria diaria, con nombres independientes para cada control.

AspectoComportamiento
Nombre y relaciónEl label de fecha se asocia al trigger con un id estable; las horas anuncian “Hora de inicio” y “Hora de fin”, además del label visible de la ventana.
Calendario emergenteEl trigger expone aria-haspopup="dialog", aria-expanded y aria-controls; la grilla anuncia cada fecha y el estado del rango.
Ayuda y errorhelperText y errorText se relacionan con el trigger y los dos combobox mediante aria-describedby.
TecladoEl calendario admite navegación por flechas, Home/End, PageUp/PageDown y selección por Enter/Space; Escape cierra y restaura el foco.
RangoEl primer clic deja un extremo pendiente y el segundo completa el rango; disabledDates, minDate y maxDate evitan selecciones imposibles.
AccionesEl botón de limpiar tiene nombre accesible, entra en el orden de tabulación y devuelve el foco al trigger de fechas.

Lineamientos de uso

Utiliza el rango cuando la hora se repite para cada día del periodo y reserva espacio para la selección abierta.

Recomendado

Explica que la ventana horaria aplica a todos los días del rango.

Evita

No uses este control para dos momentos independientes de inicio y fin.

Usa Date time picker para un único momento.
Recomendado

Deshabilita días no operativos antes de que el usuario complete el rango.

Evita

No abras el calendario sin espacio reservado: el overlay no debe tapar la siguiente sección.
