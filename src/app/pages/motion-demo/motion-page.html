Animaciones / Motion

Motion

Primitivo de animación de entrada/salida: envuelve contenido y lo anima según un booleano show, siempre a partir de los tokens --motion-duration-* y --motion-easing-* — nunca un número suelto. Un preset elige QUÉ anima (fade, scale, slide-*); duración y curva de entrada/salida se pueden ajustar por separado.

Playground

Ajusta el preset y el estado para explorar la animación.

Presets

Las seis animaciones disponibles. Cada tarjeta se puede repetir por separado.

@for (p of presets; track p) { }

Lineamientos de uso

Recomendado

Ata show a una condición real (un estado de error, un menú abierto).

<cs-motion [show]="hasError" preset="slide-down">
  <app-error-message />
</cs-motion>
Evita

No envuelvas contenido que siempre está visible: show fijo en true no tiene nada que animar.

<cs-motion [show]="true">
  <app-page-header />
</cs-motion>
Recomendado

Deja los valores por defecto de duración/easing salvo que el caso lo pida — ya están emparejados (entering con enter, leaving con exit).

<cs-motion [show]="open" preset="scale" />
Evita

No alargues la salida de un menú "para que se vea mejor": rompe el criterio de que salir siempre es más rápido que entrar.

<cs-motion [show]="menuOpen" exitDuration="slow" />
Recomendado

Usa spring para un momento puntual que busca atención — un badge que aterriza, un estado de éxito.

<cs-motion [show]="justSaved" enterEasing="spring">
  <app-success-badge />
</cs-motion>
Evita

No uses spring en transiciones cotidianas: el rebote compite por atención con algo tan frecuente como un menú.

<cs-motion [show]="open" enterEasing="spring">
  <app-dropdown-menu />
</cs-motion>
Recomendado

Elige la dirección del slide según de dónde llega el contenido en el layout real.

<cs-motion [show]="open" preset="slide-down">
  <app-top-banner />
</cs-motion>
Evita

No uses un slide lateral para algo que aparece centrado en pantalla: la dirección deja de tener referencia espacial.

<cs-motion [show]="open" preset="slide-left">
  <app-centered-modal />
</cs-motion>

Propiedades

PropiedadTipoPredeterminadoDescripción
showboolean—Controla si el contenido está montado. Al pasar a false, anima la salida y recién ahí se quita del DOM.
presetMotionPreset"fade"Qué anima: fade, scale, slide-up, slide-down, slide-left o slide-right.
enterDurationMotionDurationToken"entering"Token de duración para la animación de entrada.
exitDurationMotionDurationToken"leaving"Token de duración para la animación de salida.
enterEasingMotionEasingToken"enter"Token de curva para la animación de entrada.
exitEasingMotionEasingToken"exit"Token de curva para la animación de salida.
innerClassstring—Clase CSS adicional para el contenedor animado.
