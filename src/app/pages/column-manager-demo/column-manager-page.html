Componentes / Column manager

Column managerNuevo · v0.3.12

Column manager deja que cada persona elija qué columnas ve en una tabla y en qué orden. Úsalo en matrices con muchas columnas, junto a la barra de la tabla. El consumidor guarda la elección y la aplica a Table. En una tabla con pocas columnas fijas, muestra las columnas directamente sin este control.

Playground

Abre el menú, oculta o muestra columnas y cámbialas de orden. El mínimo visible impide ocultar todas.
