Toggle

Un toggle (interruptor) permite activar o desactivar un ajuste. Representa un estado binario y opcionalmente lleva una etiqueta y una descripción.

Ajusta los controles para explorar todas las variantes del toggle.

Tamaños

Tres tamaños para adaptarse a la densidad de la interfaz. sm=28×16px · md=36×20px · lg=44×24px.

Con descripción

Añade una línea secundaria debajo de la etiqueta para dar contexto adicional.

Accesibilidad

El componente conserva un input checkbox nativo con role="switch" para comunicar un ajuste encendido o apagado sin recrear su semántica con ARIA manual.

AspectoComportamiento
Nombre accesibleUsa label en los casos normales. Si el interruptor no tiene texto visible, proporciona aria-label.
TecladoTab lleva el foco al interruptor y Espacio alterna entre encendido y apagado.
SemánticaEl lector de pantalla anuncia un switch y su estado marcado; úsalo para ajustes binarios que pueden aplicarse de inmediato.
Estado deshabilitadoEl control no recibe interacción ni foco y conserva la semántica disabled del navegador.

Lineamientos de uso

Cada fila compara una práctica recomendada con un uso que se debe evitar.

Recomendado

Usa Toggle cuando el cambio se aplica de inmediato.

Evita

No lo uses si todavía hace falta guardar o confirmar el cambio.

Save changes
Recomendado

Formula la etiqueta como una opción o estado, no como una pregunta.

Evita

No uses preguntas: el estado del interruptor ya responde si está activo.

Recomendado

Mantén el cambio directo y visible en el momento de alternar.

Evita

No agregues un botón secundario “Apply” para un ajuste que ya representa una decisión inmediata.

Apply
Recomendado

Explica la consecuencia cuando activar el ajuste cambia la visibilidad o el alcance.

Evita

No omitas contexto cuando la decisión tiene una consecuencia relevante.
