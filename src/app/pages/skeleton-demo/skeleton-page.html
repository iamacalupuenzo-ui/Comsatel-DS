SkeletonNuevo en el sitio · v0.3.12

Skeleton reserva el espacio de un contenido que todavía se está cargando, con la forma aproximada del resultado. Úsalo cuando la espera es breve y la forma del contenido es predecible; para esperas largas o sin forma conocida, usa Progress indicator.

Playground

Elige la variante y el ancho. Arriba del ejemplo se explica cuándo usar la variante elegida.

  • {{ info().label }}. {{ info().when }}
  • Propiedades: variant="{{ variant() }}"

Casos de uso

Tarjeta de unidad

Mientras llega la telemetría: el círculo reserva el ícono y dos líneas, el nombre y la ubicación.

Filas de tabla

Mientras se cargan los datos de una matriz: una línea por celda, con anchos distintos para que se lea como tabla.

@for (row of [1, 2, 3]; track row) {
}
