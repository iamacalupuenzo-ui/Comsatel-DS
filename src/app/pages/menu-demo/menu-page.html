Menu

Menu es la lista de navegación reutilizable con la que se arma un side nav: grupos de ítems con ícono, badge, atajo de teclado, y un nivel de hijos anidados. Se renderiza en modo expandido (labels completos) o rail (solo íconos, con flyout). A diferencia de Dropdown, Menu nunca dispara una acción — cada ítem es un link real a algún lado.

Lineamientos de uso

Recomendado

Agrupa ítems relacionados bajo un header de grupo — ayuda a escanear un menú largo.

groups=[{header:'Gestión', items:[...]}]
Evita

No crees un grupo con header para un solo ítem — un header sin más de un ítem debajo no aporta nada al escaneo.

groups=[{header:'Ayuda', items:[uno]}]
Recomendado

Pasa siempre activeHref atado a la ruta actual, para que el ítem correspondiente se resalte solo.

[activeHref]="router.url"
Evita

No manejes el estado activo/resaltado a mano por fuera de activeHref: tarde o temprano se desincroniza de la ruta real.

activo = signal('/dashboard')
Recomendado

Usa Menu solo para ítems que navegan a un href real.

Evita

No uses Menu para disparar acciones como exportar o eliminar: para eso está Dropdown.

{ label: 'Exportar CSV', href: '#', (click): ... }
Recomendado

Mantén los hijos en un solo nivel: un header de grupo, sus ítems, y como mucho un nivel de hijos anidados.

Evita

No anides hijos dentro de hijos: el tipo de Menu no lo permite, y un tercer nivel es difícil de escanear dentro de un flyout de rail.

children: [{ ..., children: [...] }]

Menu: Propiedades

PropiedadTipoPredeterminadoDescripción
groupsMenuGroupData[]—Array de grupos de ítems, cada uno con un header opcional.
mode"expanded" | "rail""expanded"expanded: labels completos. rail: solo íconos, con flyout al pasar el mouse o enfocar.
activeHrefstring—El href que debe mostrarse resaltado.
(navigate)EventEmitter<void>—Se emite al hacer clic en cualquier link — útil para cerrar un drawer mobile.

MenuGroupData: Forma

PropiedadTipoPredeterminadoDescripción
headerstring—Label opcional arriba del grupo en modo expandido. Se oculta en modo rail.
itemsMenuItemData[]—Los ítems del grupo.

MenuItemData: Forma

PropiedadTipoPredeterminadoDescripción
labelstring—Texto del ítem.
hrefstring—Ruta real a la que navega.
iconIconName—Obligatorio en la práctica para que el ítem sea usable en modo rail.
badgestring—Contador corto, se muestra como badge circular.
shortcutstring[]—Atajo de teclado. Solo se muestra, el atajo en sí lo dispara quien consume Menu.
disabledbooleanfalseNo navega, se atenúa.
childrenMenuItemData[]—Un solo nivel de hijos — no anidan más.
