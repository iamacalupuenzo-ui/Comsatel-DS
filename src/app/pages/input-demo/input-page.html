Accesibilidad

Input conserva un elemento input nativo y permite asociar etiquetas, ayudas y errores sin depender del placeholder.

AspectoComportamiento
Nombre accesibleAsocia una etiqueta visible con id/for o usa aria-label/aria-labelledby cuando el contexto lo requiera.
Ayuda y errorRelaciona la ayuda o el error con aria-describedby. invalid expone aria-invalid="true" y siempre debe acompañarse de un mensaje específico.
Teclado y semánticaEl elemento nativo conserva escritura, selección, foco, Tab, Enter y las teclas propias de cada type. disabled y readonly mantienen su semántica nativa.
InputGroupEl grupo conserva role="group"; InputGroupInput recibe los atributos accesibles y los addons solo complementan el campo. Un selector de país conserva texto para el lector de pantalla: la bandera es decorativa.
ContenidoUsa un placeholder como ejemplo, no como etiqueta. Reenvía name, autocomplete, required, límites y atributos ARIA al input real.

Lineamientos de uso

Cada fila compara una práctica recomendada con un uso que se debe evitar.

Recomendado

Agrega un ícono que refuerce el propósito del campo sin reemplazar su nombre accesible.

Evita

No dependas solo del placeholder como etiqueta visible: desaparece al escribir.

Recomendado

Combina el estado inválido con un mensaje que indique qué corregir.

Enter a valid email address.

Evita

No marques un campo como inválido solo con el borde rojo.

Recomendado

Mantén todos los campos de un mismo formulario en el mismo tamaño.

Evita

No mezcles tamaños sm y lg en un mismo formulario sin una razón de jerarquía.

Recomendado

Permite mostrar u ocultar la contraseña para que el usuario pueda verificar lo escrito.

Evita

No fuerces una contraseña oculta sin forma de revelarla antes de enviarla.
