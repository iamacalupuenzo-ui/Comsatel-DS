Cómo usar los íconos

  • Usa el mismo símbolo para la misma acción. Acompaña las acciones ambiguas con texto.
  • El tamaño depende de los tokens de layout; el color se hereda del texto mediante currentColor.
  • Un ícono decorativo se oculta a lectores de pantalla. Un botón que solo contiene un ícono necesita un nombre accesible.
  • Conserva el trazo y la proporción de Lucide. El área interactiva pertenece al control y puede ser mayor que el dibujo.
  • El registro cs-icon es un subconjunto curado para uso interno de los componentes; para cualquier otro ícono de este catálogo, usa el SVG directo.

Origen y referencias
