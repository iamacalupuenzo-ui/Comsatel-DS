Radio

Un conjunto de opciones mutuamente excluyentes — solo una puede estar seleccionada a la vez. Usa cs-radio-group para agrupar dos o más cs-radio, que comparten selección, tamaño y estado de deshabilitado a través del grupo.

Playground

Ajusta tamaño, orientación y estado deshabilitado del grupo.

@for (opt of colorOptions; track opt.value) { }

Tamaños

Tres tamaños, iguales a los de Checkbox — comparten escala para pesar igual en un formulario.

@for (size of sizes; track size) {
{{ size }}
}

Con descripción

Una segunda línea opcional debajo del label, para dar contexto adicional sin salir del grupo.

Deshabilitado

Una opción puntual, o el grupo completo.

Requerido y validación

Label, asterisco de requerido, y mensaje de error a nivel de grupo.

Accesibilidad

Radio conserva un input type="radio" nativo para delegar al navegador la semántica, el foco y la navegación de teclado, mientras el grupo relaciona su label, ayuda y error mediante atributos ARIA.

AspectoComportamiento
Nombre accesibleCada opción usa su label visible. Si el texto no se muestra, pasa aria-label al cs-radio; el label del grupo no sustituye el nombre de cada opción.
Semántica de grupocs-radio-group expone role="radiogroup", comparte un name nativo y relaciona su label con aria-labelledby.
TecladoTab entra al radio seleccionado (o al primero disponible) y las flechas del navegador cambian la selección dentro del mismo grupo; Espacio activa el radio enfocado.
Requerido y errorrequired se reenvía a los inputs y aria-required/aria-invalid describen el estado. helperText o errorText se enlazan mediante aria-describedby y el error también se anuncia con aria-errormessage.
DeshabilitadoLa opción o el grupo conserva disabled nativo, no entra en el orden de foco y mantiene la relación visual con su etiqueta.

Lineamientos de uso

Recomendado

Preselecciona una opción razonable por defecto cuando exista una — reduce fricción, la mayoría de usuarios no cambia el default.

Evita

No dejes un grupo de radios sin ninguna opción marcada cuando una elección clara ya existe — obliga a pensar donde no hace falta.

Recomendado

Usa Radio para 2-6 opciones mutuamente excluyentes, todas visibles a la vez.

Evita

No uses Radio para listas largas (10+ opciones) — un Select/Dropdown busca y escala mejor.

<cs-input-dropdown [options]="paises">
Recomendado

Usa description cuando el label solo no basta para decidir.

Evita

No metas todo el detalle dentro del label mismo — se vuelve difícil de leer y rompe la alineación del grupo.
