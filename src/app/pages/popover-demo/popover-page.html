Popover

Un popover muestra contenido breve y efímero anclado a un trigger — un menú de acciones, una lista de dispositivos, un detalle rápido. A diferencia de Modal, nunca bloquea el resto de la página y se cierra con un clic afuera o Escape sin preguntar. Para una interrupción de página completa que necesita una decisión, usa Modal en su lugar.

Lineamientos de uso

Recomendado

Usa Popover para contenido ligado a un solo trigger — un menú de acciones, un panel corto de detalle, una lista de dispositivos.

Acciones
Evita

No uses Popover para un flujo que necesita una decisión o bloquea el resto de la página — una confirmación destructiva, un formulario obligatorio. Para eso usa Modal.

Requiere confirmación en Modal
Recomendado

Deja que un clic afuera y Escape lo cierren sin confirmación — un popover está pensado para descartarse de forma casual.

Accesibilidad

Popover mantiene el contexto de la página y expone la relación entre el trigger y el panel para tecnologías de asistencia.

AspectoComportamiento
RelaciónAl abrir, el trigger recibe aria-expanded, aria-controls y aria-haspopup.
NombreUsa ariaLabel o ariaLabelledBy para describir el contenido cuando tiene role="dialog".
TecladoEscape cierra el panel y devuelve el foco al trigger. Los controles internos conservan sus teclas nativas.
Cierre casualUn clic afuera cierra por defecto; no uses este patrón para confirmar acciones destructivas.
