Guía de instalación

Cómo se consume comsatel-ds hoy, y cómo un agente de IA (o cualquier herramienta que hable MCP) accede a la librería sin tener que leer el código fuente componente por componente.

Dentro de este repositorio

Angular/Router y la librería viven en el mismo workspace (projects/comsatel-ds/). No hace falta npm install nada aparte: el proyecto ya resuelve el import from 'comsatel-ds' contra el build compilado de la librería.

Antes de usar un componente por primera vez (o después de tocar cualquier archivo dentro de projects/comsatel-ds/src/lib/), hay que compilar la librería — ng serve NO la reconstruye solo:

Desde otro proyecto

comsatel-ds todavía no está publicado en ningún registro (npm, GitHub Packages, un registro privado) — npm install comsatel-ds no funciona hoy fuera de este workspace. Si otro proyecto necesita consumirlo, hace falta agregar un paso de publicación antes; no está armado todavía.

Para agentes de IA

Este repositorio expone su superficie a un agente por dos caminos, sin que haga falta instalar nada aparte de lo que ya trae el proyecto.

adsa-cli, vía npx

Servidor MCP

.mcp.json, en la raíz del repo, ya registra un servidor MCP — cualquier cliente compatible (Claude Code incluido) lo detecta solo y expone las guías de guidelines/ como herramientas, sin configuración extra de quien lo usa.
