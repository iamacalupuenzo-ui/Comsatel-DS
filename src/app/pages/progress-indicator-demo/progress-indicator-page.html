Progress indicator

El progress indicator muestra dónde se encuentra una persona dentro de un recorrido de pasos conocido. No reemplaza una barra de carga ni una navegación entre secciones independientes.

Playground

Cambia la orientación, el paso activo y la posibilidad de volver a un paso.

Estados

Cada nodo comunica un estado textual además de su tratamiento visual.

Orientación

Usa horizontal en recorridos cortos y vertical cuando cada paso necesita más espacio descriptivo.

Interacción opcional

Cuando el flujo permite volver a un paso anterior, activa interactive y escucha stepClick.

Accesibilidad

El indicador comunica el recorrido sin convertir cada paso en navegación por defecto.

AspectoComportamiento
EstructuraUsa role="list" y cada paso se anuncia como listitem.
EstadoEl paso activo expone aria-current="step"; el texto no depende solo del color o del ícono.
InteracciónPor defecto es informativo. Con interactive, los nodos son botones nombrados y alcanzables con teclado.
ActualizacionesEl consumidor puede anunciar el paso seleccionado con una región role="status".

Lineamientos de uso

Cada par compara una práctica recomendada con un uso que conviene evitar.

Recomendado

Usa pasos breves para representar un recorrido conocido.

Evita

No uses el indicador para navegar entre secciones sin orden.

Recomendado

Activa la interacción solo cuando volver a un paso sea una acción válida.

Evita

No hagas clickeables los pasos si solo muestran el estado de un proceso.
