List item

Fila reutilizable para abrir un recurso o ejecutar una acción contextual. Su estructura contiene identidad, nombre, contexto y una zona trailing compuesta por quien la usa.

Playground

Prueba la identidad, selección y disponibilidad. El estado es contenido proyectado: reutiliza Tag cuando corresponda, sin acoplar List item a un dominio operativo.

Acciones ejecutadas: {{ actionCount() }}

Información y densidad

Cada fila contiene una sola entidad y la información necesaria para decidir si abrirla. La zona final recibe una etiqueta, fecha o acción breve sin que el componente imponga ese contenido.

Selección y disponibilidad

La selección es controlada por quien compone la lista. Una fila no disponible conserva su información, pero no recibe foco ni ejecuta acciones.

Accesibilidad

La fila usa un botón nativo: no imita el patrón listbox de PrimeNG ni inventa roles de selección para una acción de navegación.

AspectoComportamiento
SemánticaLa superficie interactiva es button; Enter y Espacio la activan con comportamiento nativo.
SelecciónCuando selectable es verdadero, aria-pressed anuncia el estado. Para opciones de formulario usa Select, que implementa listbox.
EstadoLa zona trailing compone Tag con texto e ícono; ningún estado depende exclusivamente del tono.
DeshabilitadoUsa disabled nativo: la fila sale del foco y no emite activate.

Lineamientos de uso

Cada par muestra una decisión de contenido y jerarquía.

Recomendado

Muestra una entidad y su contexto breve; compone el estado con una etiqueta existente.

Evita

No conviertas una fila genérica en un panel de telemetría; usa FleetUnitList en Mapa.

Recomendado

Usa Select para escoger una opción dentro de un formulario.

<cs-select label="País" ... />
Evita

No uses List item como sustituto de un selector con opciones y valores de formulario.
