Fundamentos / Espaciado

Espaciado

El espaciado da estructura a las interfaces. Usa padding para el espacio dentro de un contenedor y gap para el espacio entre elementos hermanos.

Fundamentos de espaciado

Un conjunto compacto de roles mantiene consistencia en los layouts y permite que el contenido respire.

Padding

El padding crea el espacio entre el borde de un contenedor y su contenido. Úsalo en controles, tarjetas, banners y secciones.

var(--layout-padding-xl)

Gap

El gap separa elementos hermanos en layouts flex y grid. Mantiene el ritmo del layout independiente de cada elemento.

var(--layout-gap-md)
