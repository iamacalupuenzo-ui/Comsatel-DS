Accesibilidad

Badge es una etiqueta informativa, no un control interactivo.

AspectoComportamiento
SignificadoEscribe el estado o la categoría en texto. El color y el ícono solo refuerzan ese significado; no deben ser la única señal.
InteracciónNo recibe foco ni responde al teclado. Si el estado debe abrir, filtrar o ejecutar una acción, usa un control semántico como Button.
ÍconosÚsalos como apoyo visual junto con una etiqueta legible, por ejemplo Publicado; no agregues una descripción duplicada para el ícono decorativo.
ActualizacionesUn badge no anuncia cambios por sí solo. Cuando una actualización sea importante, comunícala también mediante el patrón de notificación adecuado para el contexto.
