Tag

Los tags categorizan contenido con una etiqueta breve. Son informativos y no interactivos; el texto siempre acompaña al color y al ícono.

Playground

Explora la severidad, el tamaño, la forma y el ícono del tag.

Severidades

Elige la severidad por significado, no para decorar una etiqueta sin contexto.

@for (severity of severities; track severity) { }

Tamaños y forma

Usa la escala para mantener la densidad del contexto y la forma redondeada para estados compactos.

Con íconos

El ícono refuerza el significado y proviene del registro curado; el texto sigue siendo la señal principal.

Accesibilidad

Tag es una etiqueta informativa, no un control interactivo.

AspectoComportamiento
SignificadoEl valor visible comunica la categoría o el estado. El color y el ícono solo lo refuerzan.
InteracciónNo recibe foco ni responde al teclado. Para acciones, usa Button u otro control semántico.
ÍconoEs decorativo y acompaña al texto; todos los íconos salen del registro curado.
ActualizacionesUsa aria-live="polite" solo cuando el valor cambie dinámicamente y deba anunciarse.

Lineamientos de uso

Cada par contrasta una práctica recomendada con un uso que conviene evitar.

Recomendado

Escribe una etiqueta breve que explique la categoría.

Evita

No uses el tag como un párrafo o mensaje largo.

Recomendado

Combina texto e ícono cuando el estado se beneficia de una señal visual adicional.

Evita

No comuniques un estado solo con color o con un ícono sin texto.

Recomendado

Usa la forma redondeada para estados compactos que se repiten en una lista.

Evita

No mezcles formas para comunicar el mismo estado dentro de una fila.
