Motion tokens

Duración y curva de aceleración son tokens, igual que el color o el espaciado: una escala fija y nombrada en vez de un número elegido al ojo cada vez. Cada transición animada de este sistema — un chevron que rota, un flyout de menú, un dropdown que se abre — usa uno de estos, nunca un valor suelto en milisegundos.

Duración

Cinco pasos. Más corta para movimientos chicos y frecuentes (un hover, un chevron); más larga para contenido que entra o sale del layout.

@for (d of durations; track d.token) { }

Curvas de aceleración

Cuatro curvas. Cada una va emparejada con un tipo de movimiento específico — usar la que no corresponde es la forma más común de que una transición se sienta un poco mal aunque la duración esté bien.

@for (e of easings; track e.token) { }

Lineamientos de uso

Recomendado

Usa un token de duración y una curva con propósito: entering con enter, o leaving con exit.

Evita

No escribas milisegundos o curvas en cada componente: se desincronizan cuando evoluciona la escala.
