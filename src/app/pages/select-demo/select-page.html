SelectActualizado · v0.3.4

Select permite elegir uno o varios valores dentro de un formulario, a diferencia de Dropdown, que dispara acciones. En modo múltiple, las opciones elegidas se muestran como chips dentro del propio campo y cada una tiene una acción para quitarla.

Texto largo en un espacio acotado

El campo y los chips respetan el ancho disponible. Oculta la limpieza cuando el valor sea obligatorio; reelegir conserva la selección.

Selecciona una operación antes de continuar.

Densidad del modo múltiple

Compara 2, 5 y 12 opciones en los cuatro tamaños. Chips conserva dos valores y un +N en una línea; summary muestra el conteo. Con las 12 opciones marcadas, ambos muestran «todos».

Lineamientos de uso

Recomendado

Acompaña siempre el Select de un label en contextos de formulario, igual que cualquier otro campo.

Evita

No omitas el label: el usuario pierde contexto sobre qué está eligiendo.

Recomendado

Usa multiple cuando el usuario puede elegir más de un valor a la vez; las opciones elegidas quedan visibles como chips.

Evita

No actives multiple si el formulario solo admite un valor final: agrega ambigüedad donde no la hay.

Recomendado

Si son solo 2 o 3 opciones mutuamente excluyentes y siempre visibles, evalúa un Toggle o un grupo de Radio en vez de un Select.

<cs-radio-group>
Evita

No uses Select para 2 opciones que caben cómodamente como Toggle: agrega un clic extra sin necesidad.
