SelectActualizado · v0.3.4

Select permite elegir uno o varios valores dentro de un formulario o de una barra de filtros, a diferencia de Dropdown, que dispara acciones. En modo múltiple, la selección se muestra como chips (una insignia por opción) o como un resumen de una línea.

Estados

Cada estado en su propio ejemplo, con cuándo usarlo y el código que lo produce. El foco y la apertura tienen prioridad sobre el filtro aplicado, y el error sobre ambos.

Vacío

Todavía no se eligió nada. El placeholder dice qué se espera.

Con valor

Hay una opción elegida. Con la X se limpia, salvo que el valor sea obligatorio ([showClear]="false").

Filtro aplicado

Solo en barras de filtro: indica que el resultado está restringido por este campo.

Error

La selección no cumple una validación. Siempre con un mensaje que explique cómo resolverlo.

Selecciona un equipo antes de continuar.

Requerido

El formulario no se puede enviar sin este valor. El asterisco aparece junto al label.

Solo lectura

El valor se muestra, pero no se puede cambiar en este contexto; por ejemplo, en un detalle ya confirmado.

Deshabilitado

El control no está disponible en el paso actual; por ejemplo, hasta completar un campo previo.

Texto largo en un espacio acotado

El campo respeta el ancho disponible: el texto se recorta con puntos suspensivos y el valor completo queda disponible al pasar el cursor.

Selección simple

Una opción larga se recorta en una línea. Aquí el valor es obligatorio, así que no se muestra la X de limpiar.

Selección múltiple con chips

Cada chip recorta su texto y, pasadas las dos opciones, el resto se resume en «+N».

Selección múltiple con resumen

Con una opción, el resumen muestra su nombre recortado; con varias, el conteo.

Lineamientos de uso

Recomendado

Acompaña siempre el Select de un label en contextos de formulario, igual que cualquier otro campo.

Evita

No omitas el label: el usuario pierde contexto sobre qué está eligiendo.

Recomendado

Usa multiple cuando el usuario puede elegir más de un valor a la vez; las opciones elegidas quedan visibles como chips.

Evita

No actives multiple si el formulario solo admite un valor final: agrega ambigüedad donde no la hay.

Recomendado

Si son solo 2 o 3 opciones mutuamente excluyentes y siempre visibles, evalúa un Toggle o un grupo de Radio en vez de un Select.

<cs-radio-group>
Evita

No uses Select para 2 opciones que caben cómodamente como Toggle: agrega un clic extra sin necesidad.
