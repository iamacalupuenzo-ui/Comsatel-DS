Table tree

Una tabla con filas jerárquicas expandibles — para datos agrupados, como unidades de flota organizadas por región. Cada fila puede tener hijos, y esos hijos pueden a su vez cargarse recién al expandir por primera vez (carga perezosa), mostrando una fila skeleton mientras tanto.

Playground

Región Norte empieza expandida. Haz clic en el chevron para expandir/contraer.

Sin resultados

Carga perezosa

Los hijos de cada región empiezan en undefined — al expandir por primera vez se muestra una fila skeleton hasta que el consumidor resuelve los datos reales (acá, simulado con un timeout de ~900ms).
